# Zun Consulting — 実務・集客導線を優先したサイト案

このサイトは、前バージョンの抽象的なコピー・カード中心の構成から、経営者が必要な情報を見つけやすい設計へ全面的に変更した静的サイトです。

## ファイルと利用方法

`index.html` がトップページ。`services/`、`cases/`、`about/`、`contact/`が独立ページです。`preview.html` は CSS・JS を内包したトップページ表示用ファイルです。`python build.py` でページを再生成できます。外部の依存関係やサービス登録は不要です。

## 設計判断

1. トップページの最初の画面で、対象（中小企業）、相談内容、相談例を説明する。
2. メニュー名・見出しは「支援内容」「相談事例」「担当者について」「相談受付について」のように内容が分かる日本語のみ使う。
3. 実際の支援経験に基づく例を掲載するが、現職の個別支援を新事業の契約実績と誤認させない。
4. 料金・所在地・資格・写真・連絡先を捏造せず、現在は開業準備中と明示する。
5. 初回相談の対応範囲・費用を約束したかのように書かず、正式な公開時に確定事項を追記する。

## 公開前の必須事項

- 実在する担当者情報（公表可能な氏名・顔写真・経歴・資格を確認）
- 適法な連絡先（メールアドレス、電話番号または実際に稼働するフォーム）
- 初回相談の料金、単発・継続支援の料金目安、サービス提供範囲、事業所所在地・対応地域
- 現職との利益相反、守秘義務、勤務先の規程への対応
- 事例の公開可否、機密情報の有無を再確認
- プライバシーポリシーとフォームへの必要な個人情報の取扱い
- `noindex,nofollow` と robots.txt の Disallow を外し、検索流入を許可（事業開始と連絡先設定の後）
- 自サイトURLが確定したら canonical と sitemap.xml を実ドメインに合わせる
- 公開後は Google Search Console の検索語、問い合わせ数、問い合わせ経路を実測して改善する

現時点ではサイトの完成度と正式な営業開始可能性を区別しています。相談先を捏造して見かけ上だけフォームを作ることはしていません。
