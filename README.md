# Zun Consulting — 静的サイト

## 概要

旧公開サイトのカード主体のデザインを全面的に見直した、依存関係のない5ページ構成の日本語サイト。HTML/CSS/最小限のJSだけで構成し、外部フォント/CDN/トラッキング/フォーム送信は使用していません。写真に見せかけた架空の成果物ではなく、独自に作成した「意思決定ノート」のSVGをヒーローに用いています。

## 編集・表示

- 文章およびHTMLの生成: `build.py`（Python標準ライブラリのみ）
- スタイル: `assets/style.css`
- モバイルメニュー: `assets/main.js`
- ビジュアル: `assets/hero-art.svg`、`assets/og.svg`
- HTML再生成: `python3 build.py`
- ローカルプレビュー: `python3 -m http.server 8000` → http://localhost:8000/
- GitHub Pages: このフォルダの中身をリポジトリのルートに設置すれば、プロジェクトパス以下で動作します（リンクは相対URL）。

## 公開前の確認

- サービス提供条件・問い合わせ受付方法が確定するまで、問い合わせページは「受付準備中」と表示します。
- 支援事例は既存公開サイトの記述をもとに編集し、支援経験・試作・構想の段階を区別しています。公開前に個人情報・守秘義務に反しないか確認してください。
- 本サイトのコードと成果物を外部へ自動公開する処理はありません。
